Tidepath staff need to reuse only approved evidence across grant answers and reconcile spending against each funder's categories and dates. This implements GrantProof as a local Next.js/SQLite app with four connected screens: evidence review, sourced application drafting, CSV spending reconciliation, and human approval/export.

Claims carry clickable source excerpts and word limits; unsupported or unapproved claims become evidence gaps. Integer-cent allocations prevent cross-grant over-allocation. Immutable approved snapshots tie the application, cited evidence, ledger and report together; edits invalidate export. Both a readable HTML report and exact JSON audit package are available. Fictional fixtures include a second fiscal period and documented expected totals.
